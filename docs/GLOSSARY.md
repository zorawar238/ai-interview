# Engineering Glossary

This document defines core technical terms, architecture patterns, and domain concepts used throughout the AI Coding Interview Platform.

---

### Adaptive Calibration
A dynamic evaluation mechanism where question difficulty and topic selection adjust after each question based on candidate performance metrics ($0-100$ score) rather than relying on a static pre-determined question set.

### In-Memory SQLite Runner
An execution environment where queries run against an ephemeral SQLite database located in RAM (`:memory:`) populated with sample schemas, avoiding persistent disk changes during code execution tests.

### Deterministic Fallback
A high-reliability safety mechanism that serves pre-validated, difficulty-aligned technical questions in $< 5\text{ms}$ if the local Ollama LLM is offline or encounters transient latency spikes, preventing session deadlocks.

### Row-Level Security (RLS)
PostgreSQL security policies enforced directly at the database engine level that restrict query results and mutations strictly to rows owned by the authenticated user (`auth.uid() = user_id`).

### Server-Sent Events (SSE) / Chunked HTTP Transfer
A unidirectional streaming protocol where the server keeps an HTTP connection open to stream text tokens incrementally to the client as they are generated by the LLM, dramatically minimizing Time-To-First-Token (TTFT).

### Socratic Interviewer Persona
An AI conversational system prompt configured to probe candidate reasoning, provide progressive hints, and ask clarifying architectural questions without revealing the complete solution code.

### Subprocess Isolation
A security boundary where user-submitted code runs as an isolated operating system child process (`node:child_process.spawn`) within a temporary directory with stripped environment variables (`safeEnv`) and hard execution timeouts (5s).

### Turbopack
Next.js's native Rust-based bundler and build system designed for high-performance development and production asset compilation.

### Type Stripping (`--experimental-strip-types`)
A native Node.js feature that strips TypeScript type annotations at runtime without requiring an external compilation step (like `tsc` or `esbuild`), enabling direct execution of `.ts` solution files.

### `useSyncExternalStore`
A React 18/19 hook designed for subscribing to external browser stores or non-React platform APIs (e.g., `window.SpeechRecognition`, `window.speechSynthesis`) while avoiding cascading re-renders and server-side hydration mismatches.

### Web Speech API
Standard browser APIs consisting of `SpeechRecognition` (translating spoken acoustic audio into text) and `SpeechSynthesis` (converting text strings into spoken synthetic audio).
